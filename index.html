Notice

Mesures

Transcription de l'audio

Le modèle est téléchargé une seule fois puis mis en cache par le navigateur. Le son reste sur votre machine.

Time code par phrase. Whisper date des segments de parole ; le logiciel les regroupe ou les recoupe sur la ponctuation pour obtenir une ligne par phrase. Quand un segment contient plusieurs phrases, leurs time codes sont répartis au prorata de la longueur du texte : la précision est de l'ordre de la demi-seconde. Changer le découpage ou la phrase maximale recalcule les lignes sans retranscrire.

Locuteurs

Chaque phrase reçoit une empreinte vocale (modèle WavLM, ≈ 95 Mo, téléchargé une fois) ; les empreintes proches sont regroupées en voix. Renommez ensuite chaque voix ci-dessous.

À relire. Le regroupement des voix est une aide, pas une identification : il se trompe sur les phrases très courtes, les voix proches et les paroles superposées. Indiquer le nombre de voix le rend nettement plus fiable. Corrigez chaque ligne avec son menu ; le bouton ⇣ applique le locuteur de la ligne aux lignes suivantes jusqu'au prochain changement de voix.

Texte transcrit

Lancez « Transcrire l'audio » : chaque phrase apparaîtra ici avec son time code et son locuteur.

Le texte se corrige directement dans chaque ligne. ▶ lit la phrase · ⤒ la fusionne avec la précédente · ✂ la coupe à la position du curseur dans le texte · ✕ la supprime.

Export

Aperçu de l'export 

  
Formats. Le texte brut se colle dans tout traitement de texte. Le WebVTT (.vtt) est le format des lecteurs web ; le locuteur y est porté par la balise de voix <v Nom>. Le SRT se charge dans tout lecteur ou logiciel de montage ; le locuteur y est écrit en tête de réplique. Le XML contient la notice, les locuteurs et chaque phrase avec ses time codes : il est lisible par une machine.
